# 生日派对计划工具

一个功能完整的孩子生日派对计划和管理工具，帮助家长轻松组织完美的生日派对。

## 功能特点

### 核心功能
- **派对信息管理**：记录孩子姓名、年龄、派对日期、场地、预算等基本信息
- **客人管理 + RSVP统计**：添加、删除、追踪客人RSVP状态，实时统计确认/待确认/拒绝人数
- **购物清单智能优化**：
  - 智能生成购物建议，管理采购进度，跟踪实际花费
  - 按商店分组（超市、派对用品店、蛋糕店等），优化采购路线
  - 按优先级查看（必买、推荐、可选），帮助预算决策
- **派对检查清单**：8个阶段的完整任务清单，确保不遗漏任何重要事项
- **邀请函生成**：自动生成美观的文本和HTML格式邀请函
- **预算跟踪**：实时监控预算使用情况，避免超支

### 智能建议
- 根据**派对主题**自动推荐相关装饰和用品
- 根据**孩子年龄**推荐适合的游戏和活动
- 根据**预算限制**优化购物清单
- 根据**客人数量**自动计算所需物品数量

### 支持的主题
- 超级英雄
- 公主
- 恐龙
- 海洋
- 太空
- 动物园
- 以及更多自定义主题

## 使用方法

### 快速开始

1. **运行主程序**：
```bash
cd src
python3 main.py
```

2. **创建示例派对**（可选，用于测试）：
```bash
python3 test_example.py
```

### 使用流程

#### 1. 创建新派对
- 选择"创建新的派对计划"
- 输入孩子的基本信息（姓名、年龄）
- 设置派对详情（日期、时间、场地、地址）
- 设定预算和主题
- 系统会自动生成购物清单建议

#### 2. 管理客人名单
- 添加客人信息（姓名、联系方式）
- 记录RSVP状态（待确认/已确认/已拒绝）
- 追踪额外带来的人数（+1）
- 记录特殊要求（如饮食限制）

#### 3. 管理购物清单
- 查看自动生成的购物建议（包含推荐商店和优先级）
- 添加自定义物品
- 按类别查看（装饰、食物、用品、娱乐、礼物）
- **按商店查看**：按采购地点分组，方便规划采购路线
- **按优先级查看**：区分必买/推荐/可选，预算不足时帮助决策
- 标记已购买物品并记录实际价格
- 实时查看预算使用情况

#### 4. 派对检查清单 ⭐ 新功能
- 自动生成8个阶段的完整任务清单：
  - 派对前1个月：确定日期、场地、主题
  - 派对前3周：设计邀请函
  - 派对前2周：发送邀请、预订蛋糕
  - 派对前1周：跟进RSVP、采购用品
  - 派对前3天：最后确认、采购食物
  - 派对前1天：准备装饰和游戏
  - 派对当天：布置、设置
  - 派对后：清理、感谢信
- 查看当前阶段应关注的任务
- 追踪任务完成进度
- 查看紧急待办事项（过期未完成）
- 显示整体进度百分比

#### 5. 生成邀请函
- 自动为所有客人生成邀请函
- 支持文本和HTML两种格式
- 可单独为特定客人生成
- 邀请函包含所有派对详情

#### 6. 预算监控
- 查看预估花费 vs 实际花费
- 按类别统计开支
- 剩余预算提醒
- 超支警告

- 数量
- 预估价格

- 购买状态
- 备注

## 高级功能

### 智能预算优化
当预算不足时，系统会自动按优先级筛选购物清单：
1. 用品（餐具等必需品）
2. 食物（蛋糕、饮料等）
3. 装饰
4. 娱乐
5. 礼物

### 年龄适配
根据孩子年龄自动推荐合适的活动：
- **0-3岁**：软质玩具、积木、泡泡机
- **4-6岁**：绘画套装、拼图
- **7-10岁**：桌游、手工DIY、运动器材
- **11岁以上**：电子游戏、卡拉OK、照相道具

## 数据存储

所有数据以JSON格式存储在`data/`目录下：
- 派对数据：`data/party_YYYYMMDD_HHMMSS.json`
- 邀请函：`data/invitations_party_id/`

数据格式简单，易于备份和恢复。

## 最佳实践

1. **提前规划**：至少提前2-3周开始计划派对
2. **及时更新RSVP**：收到回复后立即更新客人状态
3. **分批采购**：优先购买不易变质的物品
4. **留有余地**：建议在预算基础上预留10-15%的弹性空间
5. **确认场地**：提前确认场地容量和设施
6. **备用方案**：为室外派对准备室内备选方案

## 常见问题

**Q: 可以为多个孩子计划派对吗？**
A: 可以。每个派对都是独立保存的，您可以创建多个派对计划。

**Q: 如何修改已保存的派对信息？**
A: 加载派对后，可以在派对管理菜单中修改客人、购物清单等信息。

**Q: 邀请函可以自定义吗？**
A: 目前邀请函使用固定模板，但您可以修改`src/invitation.py`来自定义样式。

**Q: 数据会丢失吗？**
A: 所有数据保存在`data/`目录的JSON文件中，建议定期备份该目录。

**Q: 可以导出购物清单吗？**
A: 购物清单显示在终端界面，您可以截图或从JSON文件中提取数据。
